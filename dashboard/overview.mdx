The dashboard is organized around setup and connection management, not a single copy-and-paste command. The current home page focuses on OpenClaw setup, app discovery, and quick paths into the rest of the product.

## Sidebar navigation

The main sidebar is split into **Platform** and **Resources**.

| Section | What it contains |
|---|---|
| **Platform** | **Home**, **Connections**, **Usage**, **Request App** |
| **Resources** | **Settings**, **Billing**, **Feedback**, **Documentation** |

## Home page

The home page currently gives you:

- An **OpenClaw setup** card that explains browser pairing and links to **Settings > API Keys** for advanced/manual fallback
- A searchable app grid across the full integration catalog
- Sorting controls for **Live first**, **Connected first**, and **Alphabetical**
- A **Show more apps** control when the page is hiding non-live or less relevant entries by default

The home page does not currently show the old stats cards, recent requests list, or an embedded MCP command block.

## Where to go for each job

- Use **Connections** to add, reconnect, expand, or remove individual connection rows.
- Use **Usage** to inspect tool execution history, failures, and latency.
- Use **Settings** for profile, advanced/manual API keys, and account security handoff.
- Use **Billing** for plan status, upgrade, and subscription management.
