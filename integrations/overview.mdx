Integrations let your ClawLink agents connect to the tools you already use. Once you add credentials for a service, your agent gains a set of tools it can call — reading data, triggering actions, and moving information between services — all in response to natural language instructions.

## How to connect an integration

<Steps>
  <Step title="Open the Integrations page">
    Go to your ClawLink dashboard and select **Integrations** from the sidebar.
  </Step>
  <Step title="Choose a service">
    Find the integration you want and click **Connect**.
  </Step>
  <Step title="Authorize or enter credentials">
    For OAuth-based integrations (like Gmail or GitHub), you'll be redirected to the service to authorize access. For API key integrations, paste your key into the form.
  </Step>
  <Step title="Start using it">
    Your agent can now use the integration immediately. Just describe what you want in plain language.
  </Step>
</Steps>

## Additional integrations

ClawLink also supports the following services. Connect them from the [Integrations dashboard](/dashboard/integrations) the same way as any other integration.

**Data & Analytics** — Google Analytics, Mixpanel, Segment

**Storage & Databases** — AWS S3, Supabase, Firebase

**E-commerce** — Shopify, WooCommerce

**Content & CMS** — WordPress, Webflow, Ghost, Contentful

<Note>
  ClawLink stores your credentials encrypted at rest and never exposes them to your agent in plain text. Your tokens and API keys are only used to make authorized requests on your behalf.
</Note>
