Integrations let your ClawLink agents connect to the tools you already use. Once you add a connection for a service, your agent gains a set of tools it can call for reading data, triggering actions, and moving information between services.

## How to connect an integration

<Steps>
  <Step title="Open the Connections page">
    Go to your ClawLink dashboard and select **Connections** from the sidebar.
  </Step>
  <Step title="Choose a service">
    Find the app you want and click **Connect** or **Add connection**.
  </Step>
  <Step title="Finish the hosted flow">
    ClawLink opens the provider flow in a popup and creates or updates the exact connection row for that app.
  </Step>
  <Step title="Start using it">
    Your agent can now use the integration immediately through the OpenClaw plugin.
  </Step>
</Steps>

## Additional integrations

ClawLink also supports the following services. Connect them from the [Connections page](/dashboard/integrations) the same way as any other app.

**Data & Analytics** — Google Analytics, Mixpanel, Segment

**Storage & Databases** — AWS S3, Supabase, Firebase

**E-commerce** — Shopify, WooCommerce

<Note>
  ClawLink stores your credentials encrypted at rest and never exposes them to your agent in plain text. Your tokens and API keys are only used to make authorized requests on your behalf.
</Note>
